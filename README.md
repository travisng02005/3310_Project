Instructions to run in Android Studio:

    1. Extract the zipped folder
    2. Open Android Studio.
    3. Select "Open an existing Android Studio project" or "File" > "Open."
    4. Navigate to the extracted project folder on your hard drive and select it. Android Studio will then import and open the project.
